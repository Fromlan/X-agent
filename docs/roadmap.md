# X-agent 路线图

本页保留后续方向及其与现有功能的区别，不作为排期承诺。任务范围、优先级与交付状态以 [GitHub Issues](https://github.com/Fromlan/X-agent/issues) 和 PR 为准；已发布变更见 [CHANGELOG.md](../CHANGELOG.md)，当前能力见 [README.md](../README.md)。

旧版路线图中的月份、人天估算、依赖图、已完成任务的实施清单及失效路径已移除。当前仍只有 `apps/desktop` 一个应用，发布与 CI 聚焦 Windows；现有 Godot RPC 继续使用。

## 当前已具备的基础

| 方向 | 当前实现 | 后续边界 |
|---|---|---|
| 工程检查 | 离线断言、Vitest 覆盖率、Playwright E2E、真实 Godot 集成、actionlint | 扩展检查须依据实际缺口，不再重复规划已落地的框架 |
| Godot 工具 | 场景内省、运行报错、脚本检查、资源治理、断点、配置及导出 | 工具与协议以共享注册表和插件说明为准 |
| 文件引用与界面契约 | `@` 路径补全、模式切换、虚拟列表与撤回回归 | 交互细项单独记录 Issue |
| 诊断与恢复 | 本地诊断预览、导出、反馈摘要与崩溃恢复处理 | 当前不自动上传诊断；不将早期 Sentry 方案视为既定实现 |
| CI 与发布 | 五个 CI job；发布前验证 tag、包版本、更新说明及实际检查结果 | 当前工作流见 `.github/workflows/` |

## 后续候选方向

下列编号保留为旧任务的检索线索，不代表执行顺序。旧方案中的文件名、IPC 名和技术选型需在具体任务开始时重新核对。

| 原编号 | 方向 | 尚需明确的范围 |
|---|---|---|
| 2.1 | 会话导出、导入与复现 | 对话、工具结果、文件路径与检查点的可迁移格式和脱敏边界 |
| 2.2 | 开发者诊断深化 | 在现有本地诊断之上按实际排障需要补充，不重复建设诊断入口 |
| 2.3 | Plan 与 Skill 模板 | 模板管理、生成位置及重载体验 |
| 2.4 | 崩溃诊断深化 | 先评估现有本地记录与恢复的缺口；外部上报属于单独决策 |
| 2.5 | 可访问性自动化 | 键盘可达性、焦点管理与自动检查 |
| 2.6 | 外部 GDScript 检查与格式化 | 工具发现、用户配置及与已有 Godot lint 的配合 |
| 2.7 | 提交与 PR 描述草稿 | 生成、预览与复制体验；不隐含自动提交或发布 |
| 3.1 | Package 浏览与发现 | 来源、搜索及供应链约束；复用现有安装流程 |
| 3.2 | 主题 token 编辑器 | 预览、持久化、导入导出及可访问性 |
| 3.3 | 快捷键管理 | 统一列表、搜索、重绑定与冲突处理 |
| 3.4 | 浏览器访问的长期探索 | 尚无独立 Web 应用；需重新评估部署、认证与桌面能力边界 |
| 3.5 | 多项目工作区深化 | 在现有项目分组与 Godot 多客户端之外，明确同时运行会话的模型 |
| 3.6 | 会话时间线 | 长会话定位、历史预览与文件检查点的关系 |
| 3.7 | CI 持续改进 | 基于现有五个 job 处理速度、稳定性与遗漏检查 |
| 3.8 | 性能观测 | 采样成本、展示方式和数据保存范围；外部遥测另行决策 |

## 已取消的方向

早期 1.3「界面国际化」计划已取消；当前用户界面以中文为主，中英文 README 分别维护。它不再作为其他任务的前置依赖。

## 维护方式

新增工作先在 Issue 明确问题、范围和验收方式；有交付后更新用户文档和更新说明。路线图只保留仍有意义的方向，不复制测试结果、源码片段或逐版本完成记录。工程检查与发版流程见 [CLAUDE.md](../CLAUDE.md) 和 [维护说明](maintenance.md)。
